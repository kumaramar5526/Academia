# Academia Inspired Education Website

Custom Responsive Layout Built Using HTML5 and CSS3

## Overview

This project is a fully responsive educational website built entirely from scratch using HTML5 and CSS3. The design inspiration was taken from a modern eLearning platform layout, and the interface was manually recreated without using Bootstrap, JavaScript, or any external frameworks.

The objective of this project was to reverse engineer a professional grade UI and implement it using core front end fundamentals, focusing purely on layout accuracy and responsiveness.

---

## Key Features

- Fully responsive layout across desktop, tablet, and mobile devices
- Custom header with angled call to action button
- Multi section homepage structure
- Flexbox based navigation and alignment
- Structured and semantic HTML5 markup
- Clean spacing and typography system
- Built without frameworks
- No JavaScript used
